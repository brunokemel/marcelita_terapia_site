# Marcelia Corrêa — Landing page

Landing page responsiva em React, TypeScript e Styled Components para divulgação de terapia energética.

## Rodar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Personalização rápida

- Conteúdo dos atendimentos: `src/domain/services.ts`
- Paleta visual: `src/styles/theme.ts`
- Textos e seções: `src/App.tsx`
- Número do WhatsApp: ajuste o método `whatsapp()` em `src/domain/services.ts` adicionando o número internacional no endereço `https://wa.me/`.

Os serviços exibidos são uma proposta editorial inicial e devem ser ajustados aos atendimentos efetivamente oferecidos pela profissional. A área com o monograma “M” está preparada para receber uma fotografia real da Marcelia.
